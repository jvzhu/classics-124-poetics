# Classics 124: Comparative Poetics

Comps-prep notes on classical poetics (UC Berkeley, Classics 124), extended into a comparative research project connecting Western poetics — Plato, Aristotle, Longinus, Sidney — with the Ming-Qing Chinese commentarial tradition (Zhang Zhupo on *Jin Ping Mei*) and Judith Butler's performativity framework.

## Core Threads

- **[Western Poetics Synthesis](western-poetics-synthesis.md)** — Plato through Sidney, key arguments and cross-references
- **[Roy Translation / Recension Crux](roy-translation-recension-crux.md)** — the *cihua* vs. *xiuxiang* recension problem underlying the benchmark design
- **[Zhang Zhupo vs. Chongzhen Commentator](zhang-zhupo-vs-chongzhen.md)** — commentarial tradition comparison
- **[Benchmark Design](benchmark-design.md)** — recension-aware LLM benchmark project overview
- **[Mimesis to Performativity](mimesis_to_performativity.md)** — Butler's framework in dialogue with classical mimesis

## About This Project

This repository supports a recension-aware benchmark for evaluating LLM performance on classical Chinese fiction commentary, distinguishing textual traditions (Recension A/B) that are frequently conflated in translation and downstream analysis.
